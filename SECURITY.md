# Security Policy

## Supported versions

Only the latest release (see [releases](https://github.com/DeaDoes/Tappy/releases/latest)) receives security updates.

## Reporting a vulnerability

Please **do not** open a public issue. Instead, open a [private security advisory](https://github.com/DeaDoes/Tappy/security/advisories/new) or contact the maintainers directly.

Include what you knocked loose: affected version, steps to reproduce, and impact. We'll acknowledge within a few days and coordinate a fix before disclosure.
